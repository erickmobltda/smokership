# Smokership

Discover, rate and keep track of your cigars. A revival of the 2021 Smokership app ([cigarsDb](https://github.com/erickmobltda/cigarsDb) + [cigarsDbBackEnd](https://github.com/erickmobltda/cigarsDbBackEnd)), rebuilt on the shared erickmob stack.

**Live:** https://smokership.erickmob.dev

## What it does

- **Discover:** search and filter 9,931 cigars (country, size, strength, Cigar Aficionado score). Works without login.
- **Cigar page:** specs, CA scores over the years, community tastings; rate it, add it to the humidor or the wish list.
- **Humidor:** what you have (with quantities), your wish list and everything you've tasted.
- **Feed:** latest tastings from everyone.
- **Profile:** display name, stats, language (PT-BR / EN).

Sign-up is off (shared Firebase project): accounts are created in the Firebase console.

## Stack

- React 18, Vite, TypeScript, Tailwind, TanStack Query, i18next
- Firebase Auth + Firestore, project `erickmob-apps`:
  - `apps/smokership/users/{uid}/{profile,humidor,wishlist}` — private
  - `apps/smokership/ratings/{uid}_{cigarId}` — tastings, readable by signed-in users
  - rules and tests live in `erickmob-api/firebase/`
- Catalog: `public/catalog.json`, generated by `scripts/build_catalog.py` from the old Flyway loads in `data/legacy/`. Repeated Cigar Aficionado rows (one per review) are merged by name and keep every score.
- Images: `https://api.erickmob.dev/smokership/images/{id}.webp` (erickmob-api → private bucket `erickmob-files`, cached by Cloudflare). Converted with `scripts/convert_images.py`.
- Hosting: GitHub Pages, custom domain via the `cname` in `.github/workflows/deploy.yml`.

## Run locally

```bash
cp .env.example .env.local   # fill the Firebase web app values
npm install
npm run dev
```

## Repo secrets

| Name | Value |
| --- | --- |
| `VITE_FIREBASE_API_KEY`, `VITE_FIREBASE_APP_ID` | `firebase apps:sdkconfig WEB <smokership appId> --project erickmob-apps` |
| `VITE_FIREBASE_AUTH_DOMAIN` | `erickmob-apps.firebaseapp.com` |
| `VITE_FIREBASE_PROJECT_ID` | `erickmob-apps` |

## Regenerate the catalog

```bash
npm run catalog
```
